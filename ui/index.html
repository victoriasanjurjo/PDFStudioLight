        Acerca de PDF Studio Light

        Aplicación nativa de alto rendimiento con Rust y Tauri v2.

        Arquitectura Local-First y Seguridad

        Esta aplicación opera 100% de manera local y offline. Ningún documento o firma es enviado a servidores remotos.

        🔒 Mitigación Zip Slip

        Protección contra desbordamiento o sobrescritura de directorios padre al descomprimir archivos ZIP.

        🛡️ Cuotas de Memoria

        Límites estrictos de seguridad para prevenir DoS (Denegación de Servicio) por archivos inflados o Zip Bombs.

        ⚡ Motor Rust Nativo

        Procesamiento directo de flujos PDF mediante memoria segura con cero sobrecarga.
